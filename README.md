# 자산이음 (Asset Ieum)
<img width="1672" height="941" alt="자산이음" src="https://github.com/user-attachments/assets/e82d78ca-fde5-4258-8afd-9816be98a482" />

## 프로젝트 소개
> 자산 운영을 자동화하고 기업의 흐름을 연결합니다. 자산이음의 목적은 자산 요청, 승인, 구매, 지급, 반납, 회수 과정을 통합 관리하고 유무형 자산의 라이프사이클을 자동화하여 운영 효율성과 자산 관리 정확성을 높이는 것입니다.

- 유무형 자산 통합 관리
- 구매 및 재고 운영 효율화
- 운영 흐름 가시성 확보
- 자산 라이프사이클 자동화
- 데이터 기반 의사결정 지원
- 감사 추적성 강화
